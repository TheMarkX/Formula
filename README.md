# Formula

**Formula** is an interactive educational game for learning **pharmaceutics formulation and compounding concepts**.

The app turns pharmaceutical formulation steps into an interactive experience where users can explore ingredients, follow manufacturing processes, learn formulation concepts, and review important terminology through a built-in glossary.

---

## ✨ Features

- 🧪 **Interactive formulation learning**
  - Follow step-by-step pharmaceutical preparation processes.
  - Learn the purpose of ingredients and formulation steps.

- 🦷 **Dental formulation products**
  - Toothpaste
  - Mouthwash
  - Tooth powder

- 📚 **Glossary**
  - Explore important pharmaceutics terminology and concepts.

- 🧠 **Learning points**
  - Each formulation step can include educational explanations and key learning points.

- ⚗️ **Formulation quantities**
  - View formulation quantities where USP and BP information is available.

- 🧬 **Interactive 3D ingredient models**
  - Inspect ingredients using interactive 3D models.

- 🌍 **Localization**
  - English
  - Spanish
  - French
  - German
  - Designed to expand to additional languages and script variants.

- 📱 **Device language detection**
  - Uses the device's language automatically when supported.
  - Falls back to English when the device language is unavailable.
  - Remembers the language selected by the user.

- 🌓 **Light and dark themes**
  - System default
  - Light mode
  - Dark mode
  - User preference is saved between launches.

- ⚙️ **Settings**
  - Change language.
  - Change theme.
  - Configure application preferences.

---

## 🎓 Purpose

Formula is designed as an educational tool for students learning pharmaceutical sciences, particularly **pharmaceutics and formulation**.

Instead of presenting formulation information only as static text, Formula aims to make learning more interactive by combining:

> **Learning + Interaction + Visualization**

The goal is to help students understand not only **what** goes into a formulation, but also **why** ingredients and processing steps are important.
